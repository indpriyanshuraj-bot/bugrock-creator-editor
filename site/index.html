bugrock-creator-editor

A mobile-first toolkit for Minecraft: Bedrock add-ons — inspect, diagnose, fix and pack behavior and resource packs from a phone.

The web app is not built yet. It lands at v0.6.0. Until then use the CLI and TUI: bugrock diagnose <path>.
